# Gutierres Consultoria

Modelo Nuxt 4 + Tailwind para landing page de consultoria imobiliária premium.

Inclui SEO técnico com canonical, Open Graph, Twitter Card, Schema.org, `robots.txt`,
`sitemap.xml`, `ai.txt`, `llms.txt` e headers de segurança.

```bash
corepack yarn install
corepack yarn dev
corepack yarn build
```
